# Interactive Ball Simulator

这是一个交互式物理仿真器，你可以用键盘控制球体来得分。

## 功能特点

- **真实物理仿真**：包含重力、摩擦力、碰撞检测
- **交互式控制**：使用WASD键施加力到球体
- **轨迹显示**：实时显示球体的运动轨迹
- **得分系统**：球体穿过目标线段即可得分
- **力向量可视化**：显示当前施加的力

## 安装依赖

```bash
pip install pygame numpy
```

## 运行游戏

```bash
cd scripts/physics
python ball_simulator.py
```

## 游戏控制

- **W** - 向上施加力脉冲 (+y方向，持续3帧)
- **S** - 向下施加力脉冲 (-y方向，持续3帧)  
- **A** - 向左施加力脉冲 (-x方向，持续3帧)
- **D** - 向右施加力脉冲 (+x方向，持续3帧)
- **R** - 重置游戏
- **ESC** - 退出游戏

### 力脉冲系统
每次按键按下时，会添加一个持续3帧的力脉冲。多个力脉冲可以叠加，让球体获得更大的加速度。

## 游戏目标

让球体穿过红色的目标线段得分。目标线段位于屏幕右侧，垂直方向。

## 物理参数

- 重力：-9.81 m/s²
- 摩擦系数：0.5
- 球体质量：1.0 kg
- 球体半径：0.1 m
- 键盘力大小：50.0 N

## 技术实现

- 使用pygame进行图形渲染和输入处理
- 使用numpy进行数值计算
- 半隐式欧拉积分法进行物理仿真
- 库仑摩擦模型
- 弹簧-阻尼接触模型
